# GRG: настройка банкомата

## Первичная настройка Windows

1. При загрузке банкомата нажать CTRL+ALT+DEL. Выйти из пользователя АТМ нажав на Sign out и зайти под пользователем: Administrator
[img: grg_image1.jpg]

2. В настройках экрана, установить расширение 1024*768.
3. Указать имя компьютера согласно формату АТМххххх Игнорируем сообщение о перезагрузки, нажать «Restart Later».
4. Для настройки FeelView необходимо запустить AgentConfigTool.exe по пути:
5. D:\GrgBanking\FEEL_Distibution_4.0\Agent\
6. Изменить Termid на логический номер банкомата в формате 000ххххх:
7. Для сохранения изменения нажать кнопку «save».
8. Комбинацией клавиш Win+R, в диалоговом окне пропишите ncpa.cpl, нажмите [OK]. Пропишите настройки сетевого подключения.
[img: grg_image2.jpg]

9. Проверить и настроить дату, время, часовой пояс.
10. Изменить device Type на  GRG Recycler NEW
[img: grg_image3.jpg]

## Номер машины и ввод ключей

11. Корректно перезагружаете АТМ и дожидаетесь про грузки аппликаций eCat
12. После запуска аппликации, откройте лицевую дверь, отожмите красную кнопку (Service Maintenance switch), для входа в сервисное меню.
13. Пароль по умолчанию 000. Нажмите [LOGIN]
14. Нажмите [SET ATM NO.]
15. Введите номер  машины  в полях «АТМ number», «bank number». Нажмите [CONFIRM] 17.  Для выхода в меню нажмите [Switch]
[img: grg_image4.jpg]

18. Нажмите кнопку [SET MASTERKEY]
19. Введите пароль для компонента ключа А: 000000
[img: grg_image5.jpg]

20. Введите 32-значный компонент ключа A (полученный от банка) !!! для ввода 32-значного ключа дается 1 минута. по истечении времени появится сообщение «Неправильный ввод по таймауту, операция будет завершена» повторите процедуру сначала.
[img: grg_image6.jpg]

21. После ввода компонента ключа A, сверьте контрольную сумму (на фото пример). Нажмите [ВВОД] на pin-pad
[img: grg_image7.jpg]

22. Введите пароль для компонента ключа B: 000000
[img: grg_image8.jpg]

23. Введите 32-значный компонент ключа B (полученный от банка) !!! для ввода 32-значного ключа дается 1 минута. по истечении времени появится сообщение «Неправильный ввод по таймауту, операция будет завершена». Повторите процедуру заново.
[img: grg_image9.jpg]

24. После ввода компоненты ключа B, сверьте контрольную сумму (на фото пример). Нажмите [ВВОД] на Pin-pad
[img: grg_image10.jpg]

25. Сверьте итоговое значение контрольной суммы (на фото пример). Нажмите [ВВОД]
[img: grg_image11.jpg]

26. Нажмите [ВВОД] для выхода.
[img: grg_image12.jpg]

27. Запись ключа завершена. Нажмите [ОК] для продолжения.
[img: grg_image13.jpg]

## IP хоста и параметры банкомата

28. В меню супервизора нажмите [STANDARD]
29. Откройте вкладку [SYSTEM CONFIG] ➡ [SET ATM PARAM] ➡ [SET IP] – здесь задаются настройки IPадреса сервера и порт.
[img: grg_image14.jpg]

30. После изменения нажмите [CONFIRM]
31. Корректно перезагружаете АТМ
32. При загрузке банкомата нажать CTRL+ALT+DEL. Выйти из пользователя АТМ нажав на Sign out и зайти под пользователем: Administrator
33. По адресу “D:\GrgBanking\eCAT\XDC\NDC\Scripts\Param\ DataParm.xml” проверить параметр value="шестизначный номер банкомата"
34. Активировать виндовс.
35. Заменить рекламные картинки. Путь: D:\GrgBanking\eCAT\Resource\Common\Image\EN\image
37. Установить от имени Администратора NeoVideo 1.2.1, дистрибутив находится на ресурсе W:\HB\ATM_ISO\GRG\образы\GRG_win11_2025  и в образе на диске D:\Distr\ При установке указать ранее созданную папку E:\Videos

## Установка агента NeoVideo

!!! Установку агента необходимо начинать после изменения имени компьютера и перезагрузки банкомата.

!!! Если на работающем банкомате произведено изменение имени компьютера, заменены мат. плата или жесткий диск, то необходима переустановка агента NeoVideo.

1. При необходимости переустановки агента NeoVideo необходимо проверить наличие агента и произвести его удаление.
[img: grg_image15.jpg]

2. Распакуйте архив NeoVideo с последней актуальной версией в папку D:\Distr\Update.
3. Запустить Setup.exe – нажать «Далее».
[img: grg_image16.jpg]

4. Заполнить Url сервера - http://172.20.33.17:8080 ;
5. Выбрать/создать папку для хранения видео на банкомате (диск E - создать папку "Videos");
6. Далее попадаем на форму регистрации серийного номера.
[img: grg_image17.jpg]

7. Произвести настройку камер.
На банкоматах H68V/VL используется 3 камеры – фронтальная, область выдачи и сейфовой зоны, камеру внесения настраивать не нужно.
На банкоматах H48VD необходимо настроить все 4 камеры.
При выборе камеры необходимо выбрать функционал данный камеры и нажать кнопку «Настройки корректны, сохранить».
Далее необходимо выбрать из списка следующую камеру и повторить настройки.

[img: grg_image18.jpg]
Успешно настроенные камеры будут отмечены
После настройки всех необходимых камер нажмите «Далее»

## Проверка и переназначение камер

Приложение для проверки работы камер позволяет переназначить системные камеры, в случае изменения конфигурации банкомата (например, заменили камеру другой моделью). Данные изменения отправляются на сервер.
1. Зайти в папку “NeoVideo” (C:\NeoVideo)
2. Перейти в папку “NeoVideoCameraControl” и запустить NeoVideoCameraControl.exe от имени Администратора
3. После запуска будет предложено прекратить работу “NeoVideoAPI” – подтвердить;
4. Далее откроется окно, в котором будет список типов камер и предпросмотр.
[img: grg_image19.jpg]

5. Необходимо выбрать тип камеры и назначит системную камеру для выбранного типа (в момент переинициализации камер, приложение может подвисать на 2 секунды).
6. После назначения каждой камеры необходимо нажимать кнопку “настройки корректны, сохранить”;
7. Нажать кнопку “Отправить на сервер”;

До выезда на банкомат, необходимо отправить почтовое сообщение Асан Жанболату <ZHANBOLATE@halykbank.kz> для заведения серийного и логического номера банкомата в консоль NeoVideo. Если при установке агента появляется сообщение, что серийный номер не зарегистрирован, связаться с Жанболатом по средствам WhatsApp.

## Активация Windows

1. Откройте параметры системы, комбинацией клавиш WIN+I
2. Нажмите [Update & sequrity] ➡ [Activation]

[img: grg_image20.jpg]

3. Очистите защитный слой с лицензионной наклейки (на системном блоке) так, чтобы свободно читался 25-значный ключ.

[img: grg_image21.jpg]

4.Подайте интернет в системный блок, через USB кабель, с мобильного роутера или с телефона.
5. Введите 25-значный ключ

[img: grg_image22.jpg]

6. Нажмите [Activate]
[img: grg_image23.jpg]

7. Если вы получили такое сообщение об ошибке, значит нет соединения с интернетом.
[img: grg_image24.jpg]

8. При успешной активации, вы получите соответствующее сообщение.
[img: grg_image25.jpg]
